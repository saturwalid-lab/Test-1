# Nordlicht Energietechnik – Website „Das ist ein Test-Website von Satur“

Statische One-Page-Website für Photovoltaik und Batteriespeicher (HTML, CSS, JavaScript – ohne Abhängigkeiten).

## Struktur

```
index.html            Startseite
impressum.html        Impressum
datenschutz.html      Datenschutzerklärung
assets/css/style.css  Styles
assets/js/main.js     Interaktionen (Hero, Tagesverlauf, Vergleich, Rechner, Formular)
assets/img/favicon.svg
```

## Lokal ansehen

`index.html` im Browser öffnen oder einen einfachen Server starten:

```
python3 -m http.server 8000
```

Hinweis: Impressum und Datenschutz enthalten Platzhalter (fiktive Angaben) und müssen vor einer Veröffentlichung angepasst werden.
